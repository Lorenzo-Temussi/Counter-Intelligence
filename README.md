# Counter-Intelligence
A tool to reduce AI usage.

HOW TO:

Create a new Window, give it a relevant name, fill it with all the links of the tools that you're using AI to replace. It will autofill names and icons.

MILESTONES:

- actually scrapes names and icons from the page.
- save JSON of your setup to share
- option to open every page in the window at the same time
- faster editing options
- separate modes for adding and deleting elements
